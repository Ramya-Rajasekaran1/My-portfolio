# Project Design Guidelines

This document defines the design context and principles for the portfolio project. All design decisions and code changes should align with these guidelines.

## Design Context

### Users
Hiring managers, recruiters, and design peers looking for a senior UX specialist. The context is high-stakes professional review where the user needs to quickly validate skills and outcomes.

### Brand Personality
**Unique, Fluid, Human.**
The interface should feel like it was crafted by a human designer with a point of view, not a machine. It should use fluid, organic motion and avoid rigid, generic layouts.

### Aesthetic Direction
**Human-Centric & Professional.**
*   **Theme:** Forced Dark Mode with a palette of Blush, Petal, and Ivory.
*   **Anti-References:** AI-looking portfolios (glowing borders, generic card grids, gradient text, excessive glassmorphism).
*   **Accessibility:** Must be a core tenant, not an afterthought.

### Design Principles
1.  **Authenticity over Slop**: Avoid generic AI design patterns. Every element should feel intentional and unique.
2.  **Outcome-Led Storytelling**: Every case study must culminate in a clear success story or metric.
3.  **Accessible by Default**: Interaction patterns must work for all users (keyboard, screen readers, contrast).
4.  **Fluid Motion**: Use purposeful, organic animations to guide the eye and convey the "fluid" brand personality.
5.  **Professional Polish**: High-fidelity execution in typography, spacing, and hierarchy.
